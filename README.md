# Daylight — Conceptual Sketch Edition

A responsive, offline-first personal habit tracker designed to feel like an illustrated paper journal.

## Features
- Daily habit check-ins, custom habits, schedules, categories, and streaks
- Goals with progress tracking and deadlines
- Monthly calendar and a clickable 12-week habit heatmap
- Insights, consistency charts, and achievement badges
- Focus room with 25-minute focus, 5-minute break, and 15-minute break timers
- Daily journal with mood selection
- Personal greeting and four selectable paper themes: Sketchbook, Sage, Rose, and Night Ink
- Local browser storage with JSON export/import backup

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Your information is stored locally in that browser. Export a JSON backup before clearing browser data or moving to another device.

No installation, account, or backend is required.
